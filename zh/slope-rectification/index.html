01 / 边坡整治 - JKR / 政府用语

"边坡整治"在马来西亚投标语言中的含义。

边坡整治是 JKR（公共工程局）、MOW（工程部）与大多数马来西亚政府投标文件中用于描述失稳或不合规边坡上的工程修复工作的术语。它涵盖私人开发商可能称为"边坡修复"或"边坡加固"的相同范围，但用于法规背景。

如果您从 JKR 边坡工程局、地方政府（DBKL、MBPP、MBPJ、MBSA 等）或联邦机构在年检或灾后调查后收到边坡整治指令，该指令将列明：（1）边坡 ID 与位置；（2）JKR 边坡分级（I-IV）；（3）整治要求（例如"安装土钉至安全系数 ≥ 1.4"或"重建水平排水管与喷射混凝土饰面"）；（4）提交时间表；（5）预期文件（施工方法书、由注册 P.Eng. 盖章的设计计算、竣工图、测试证书）。

我们是 CIDB G7 面板注册承包商，已在通车情况下交付联邦高速、联邦铁路走廊与州属道路主管机关的边坡整治包。无论项目规模如何，文件标准都相同 - 相同的 QA/QC，相同的提交格式。

02 / 边坡整治范围

JKR 规范整治的标准解决方案包。

勘察阶段

地形测量、必要时钻孔计划（典型 30 米旋转岩芯）、原位测试（SPT、十字板剪切）、实验室分类（阿氏、筛分、三轴）、地下水观测井。SI 报告以 JKR / 欧规格式提交。

设计阶段

边坡稳定性分析（按 JKR 选项的极限平衡 / FE）、加固尺寸（按 JKR / FHWA 的土钉长度、间距、容量）、排水布置、耐久性规范。图纸 + 计算由注册 P.Eng. 盖章。

施工阶段

排水安装在前（水平排水管、地表沟渠），然后是结构加固（土钉 / 锚杆 / 锚索），然后是表面防护（喷射混凝土 / 防落石网 / 再植被）。适用时采用通车安全施工实践。

交接阶段

竣工图、拉拔测试证书（按 JKR 进行荷载测试）、注浆测试证书、排水流量记录、照片记录、维护计划。按 CIDB / 顾问规范的缺陷责任，工艺典型 12-24 个月。
