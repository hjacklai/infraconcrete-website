联邦公共基础设施 的边坡和岩土工程.

马来西亚的联邦公共基础设施项目 (高速公路、铁路、MRT、LRT、机场、港口) 在国家建设项目中承载最重的边坡和岩土工程集中度。穿过丘陵地形的 1 公里高速公路通常集成四到六种不同的岩土系统。现场交通分阶段、当局提交规则和多系统集成是反复出现的主题。

01 / 高速公路和高速公路

联邦高速公路、州 高速公路、城市道路.

联邦高速公路网络 (PLUS、NKVE、ELITE、KESAS、各种收费和非收费走廊) 和联邦/州高速公路网络共同构成马来西亚公共工程边坡工程的主要领域。

切坡稳固

高速公路切坡 (5 至 30 m 高) 在永久走廊上需要工程稳固。土钉是残积土切面的主力；岩石锚栓用于破碎岩石切面。喷射混凝土是结构皮肤。通过水平排水管在墙面后排水是最具杠杆的长期稳定剂。

填方路堤支挡

高速公路填方路堤 (尤其是穿越山谷和河流) 需要下坡侧的支挡。MSE 墙和加筋土墙是高路堤支挡的主要选择。

落石防护

穿越岩石面的切坡需要落石防护。岩石护网用于稳定的岩石面；额定 100 至 5000 kJ 的落石屏障用于松动岩石区域下方的能量拦截。

现场交通分阶段

大多数高速公路边坡工程发生在交通无法停止的运营走廊上。

02 / 联邦铁路走廊

州际铁路、货运 走廊.

马来西亚的联邦铁路包括 KTM 西海岸线、KTM 东海岸线、正在建设的新东海岸铁路链 (ECRL)，以及各种支线。

铁路走廊切填

穿越丘陵地形的长铁路对齐采用连续的切填工程。

占用窗口物流

活跃的铁路走廊在紧凑的占用窗口 (通常是夜间间隙) 上运行。

铁路上的隧道门户

当铁路穿越主要山脊或分水岭时，会出现隧道。隧道门户工程包括门户边坡稳固、预支撑系统和门户上方的集成排水。

桥梁和高架桥引道

铁路桥梁和高架桥需要稳定的引道路堤。带混凝土板饰面的加筋土 (RE) 墙处理实时火车荷载下的高土压。

03 / MRT 和 LRT 城市交通

巴生谷和槟城 城市轨道.

MRT 1、MRT 2、MRT 3 (规划中)、LRT 1、LRT 2、LRT 3、Penang LRT (规划中)。城市交通建设面临独特的岩土范畴。

地下站箱

地下 MRT 站是深箱结构 (通常在地下 25 至 35 m)。地下连续墙和连续钻孔桩墙在施工期间支挡开挖。

明挖回填段

地下站之间的明挖回填箱体携带类似的支挡范畴。

高架桥墩

高架 MRT/LRT 桥 (通常在地面以上 8 至 15 m) 位于独立桥墩基础上。

车辆段平台

火车车辆段设施 (维修、停放、清洗) 位于大型台地土方工程上。

04 / 桥梁和结构

联邦桥梁、河流穿越、 立交桥.

桥台

桥台结合三种岩土范畴：基础、回填和引道路堤。

桥墩基础

河流穿越的桥墩在活跃水道中需要基础阶段的围堰建设。

引道路堤支挡

通向桥面的引道路堤需要稳定的支挡。

05 / 隧道门户和地下

隧道门户、开挖段、 明挖回填.

门户边坡稳固

隧道门户上方的门户切面需要完全加固和表面保护。

预支撑系统

当隧道面在门户处穿越软弱地基时，预支撑系统在向前推进的隧道面前面稳固地基。

明挖回填过渡

当隧道引道太浅而无法完全开挖时，明挖回填过渡区将自然地基连接到开挖段。

门户上方的排水

隧道门户上方的地表水和地下水需要分流或截留以防止渗入工作面。

06 / 机场和港口

机场平台、港口支挡、 海事工程.

机场跑道和停机坪平台

主要机场平台 (KLIA、KLIA2、Senai、Penang International、古晋、亚庇、民都鲁、米里) 需要精确分级。

港口和集装箱码头

港口码头位于填海土地或沿海地形上。

填海和地基改良

沿海填海需要多年的沉降管理。带超载预压的竖向排水管、填料的振动压实和穿过软层的碎石桩是标准。

07 / 当局和采购框架

联邦基础设施如何运作.

  • JKR (公共工程部)作为联邦工程部门，边坡工程分支提供边坡分类提交框架。
  • LLM (马来西亚高速公路管理局)用于联邦高速公路特许合约。
  • MOW (工程部)作为监管 JKR 和 LLM 的联邦部委。
  • KKR (工程部)在早期命名法中。
  • KEKKWA用于联邦农村发展组合下的农村基础设施。
  • Prasarana (联邦所有) 用于巴生谷城市铁路上的 LRT/MRT 运营和项目交付。
  • MRT Corp用于 MRT 1、2 和规划中的 3。
  • KTMB用于联邦铁路运营。
  • MAHB用于联邦机场。
  • 采购通过 MyEPerolehan 电子招标进行大多数联邦工程。
  • 规范: JKR 公路和政府工程标准规范、BS 6031、BS 8006、BS 8081、EN 1537、EN 14487、Eurocode 7、FHWA 参考手册。
