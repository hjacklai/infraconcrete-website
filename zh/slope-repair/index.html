01 / 什么是边坡修复

将边坡恢复至安全合规状态。

边坡修复（在 JKR / 政府投标语言中也称边坡整治，当聚焦于结构加强时也称边坡加固）是将边坡在出现失稳后恢复至安全、符合设计规范状态的工程过程。失稳可以是可见的（裂缝、陡坎、渗水、结构沉降、树木倾斜）或测量的（测斜仪检测的位移、安全系数低于 1.4、表面侵蚀超出容许值）。

边坡修复不同于边坡施工。新边坡施工从零开始设计；边坡修复始于已经失稳的边坡，往往进出受限、原地基条件已被位移改变，且时间紧迫（雨季临近、施工现场需要复工）。处理不当，边坡修复后比之前更危险。处理得当，边坡比原设计规范还要坚固。

02 / 何时需要边坡修复

马来西亚条件下五大常见边坡修复触发因素。

1. 季风后失稳

季风期地下水位上升触发山坡发展、州属道路、油棕园进出道路的浅层 / 中层平移失稳。11 月至 2 月高峰。紧急边坡修复几天内动员。

2. 施工诱发失稳

平台建造期间所做的开挖暴露新坡面。应力释放 + 地下水入渗 + 热带风化 = 数周内出现裂缝。下一阶段施工前需修复。

3. 可见裂缝或陡坎

数周内裂缝扩大、结构上方出现陡坎、围栏倾斜。这些是失稳前的预警 - 在灾难性失稳前进行边坡修复。

4. 结构沉降

边坡上方的房屋、挡土墙或道路出现差异沉降。边坡正在移动。修复包括地质勘察以查找滑面，然后在其下方加固。

5. JKR / 主管机关指令

JKR 边坡工程局或地方政府（DBKL、MBPP、MBPJ、MBSA 等）在年检或灾后调查后发出边坡整治指令。合规不容置疑。我们按 JKR / 主管机关规范交付。

03 / 我们的边坡修复方法

排水优先，再做结构加固。

热带降雨是马来西亚边坡失稳的主要驱动因素 - 并非抽象意义上的"软弱土壤"，而是降雨期间 / 之后孔隙水压升高降低有效应力。我们的边坡修复默认顺序：

1. 现场勘察

目视测绘、必要时钻孔计划、实验室分类、地下水观测。输出：原因、滑面深度、安全系数计算。

2. 排水

钻进水平排水管以降低地下水位。当地下水是驱动因素时，往往是单一最有效的边坡修复措施。地表排水按规范重建。

3. 结构加固

土钉（按工程角度埋设的钢筋，注浆固结）适用于黏性土壤。锚杆适用于破裂岩石。锚索适用于高荷载挡土。尺寸恢复安全系数 ≥ 1.4（关键资产 1.5）。

4. 表面防护

当侵蚀驱动表面失稳时使用喷射混凝土饰面。当落石是隐患时使用防落石网。坡度与美观允许时再植被。
