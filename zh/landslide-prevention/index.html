01 / 两个工作窗口

失稳前预防。失稳后修复。

预防是失稳前的工程工作，对通过状况评估、监测、设计审查识别为高风险的边坡进行稳固。更便宜、更可控、可计划。

修复是边坡失稳后的纠正工作。紧急动员、一线排水与侵蚀控制、然后分阶段结构重建。更昂贵、更受限、常受公众关注。多数修复项目结合两个阶段, 立即应急稳固，然后数月内完成耐久工程修复。

02 / 识别高风险边坡

失稳前的征兆。

边坡可见迹象

张拉裂缝 (尤其顶部弯曲裂缝)、坡脚鼓胀、新地面变形、渗水带、倾斜的树木 / 围栏。

地表结构

建筑物沉降、墙体开裂、门关不上, 下方地基移动的征兆。

仪器监测数据

测压管显示地下水位上升。测斜仪显示地下移动。表面标记追踪沉降 / 侧向位移。

季风后检查

在高后果边坡上安排年度季风后步行检查。在下一个雨季捕捉到之前抓住雨季中的变化。

03 / 常见问题

业主与议会常问：

滑坡后能多快动员？ +
2-5 天，从授权开始。一线工作：水平排水管 + 侵蚀控制。
预防 vs 修复？ +
预防 = 失稳前 (更便宜、可控)。修复 = 失稳后 (紧急)。多数项目结合两阶段。
如何识别高风险边坡？ +
视觉迹象 (裂缝、渗水、鼓胀)、地表结构异常、仪器监测 (测压管、测斜仪)、季风后检查。
政府 / JKR 项目资格？ +
CIDB G7 + ISO 9001:2015。符合 JKR、LLM、MOW、KKR 资格。

有边坡风险？或者已经移动？

提供位置、观察情况和紧急程度。当日响应。
