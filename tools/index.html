How to use these

Preliminary sizing, not final design.

Each calculator returns a starting-point sizing for tender-stage estimation, BoQ build-up, and engineer review. Final geosynthetic design must run full BS 8006 / FHWA / Eurocode analysis with site-specific borehole data, peer-reviewed by a qualified geotechnical engineer. We use these same calculators internally as a first pass, then refine through Plaxis, Slide, MSEW, or hand-calc with reduction factors per ISO 13431. If you want a peer-reviewed design for a Malaysian project, send us your borehole log and section drawing through WhatsApp; same-day response from PJ HQ.
